# SEMESTER//OS
Personal fifth-semester academic command center.

## Run
Requires Node.js 18+.
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
Deploy to Vercel using framework preset **Vite**, build command `npm run build`, output directory `dist`.

## Included
- Seven subjects × five modules (35 modules)
- Module status, editable titles, difficulty, confidence, notes and review dates
- Overview dashboard and progress analytics
- Monthly calendar and daily missions
- Revision queue and weak-topic indicators
- Exam timetable placeholder for Dec 7–22, 2026
- LocalStorage persistence
- JSON export/import backup

All data stays in the current browser. Export a backup before switching devices or clearing browser data.
